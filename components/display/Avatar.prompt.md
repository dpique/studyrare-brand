User avatar — shows an image when `src` is set, otherwise initials from `name`.

```jsx
<Avatar name="Daniel Piqué" />
<Avatar src="/tutors/leann.jpg" name="Leann To" size="lg" ring />
<Avatar name="ABMGG" tone="navy" size="sm" />
```

Sizes `xs`–`xl`. Tones `brand` (periwinkle) · `amber` · `navy`. `ring` adds a periwinkle focus ring.
